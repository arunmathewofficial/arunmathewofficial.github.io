I develop scientific software for modelling the time-dependent ionisation and observable emission of astrophysical plasmas. These tools connect plasma microphysics, radiation–magnetohydrodynamic simulations, and synthetic multi-wavelength observations.

## NEMO

NEMO is a multi-ion non-equilibrium ionisation solver for astrophysical plasmas with arbitrary elemental abundances. Integrated into the PION radiation–MHD code, it follows the time-dependent ionisation state of multiple chemical elements within dynamical simulations.

[Explore NEMO](/software/nemo/){: .btn .btn--primary}

## NebulaPy

NebulaPy is a Python package for generating synthetic emission maps, line luminosities, and spectra from astrophysical simulations. It uses atomic data and emissivities from ChiantiPy to connect numerical models with multi-wavelength observations.

[Explore NebulaPy](/software/nebulapy/){: .btn .btn--primary}
